# Advance atm

In this repository, I did the analysis regarding the variations of the Trace gases and meteorology data, to find the seasonal variations and regional variations of Hyytiälä and Väriö SMEAR station. I found significant differences between CO2 and NOx gases.

# Data

The time series data have collected from the SMEAR I and SMEAR II station from 1996 to 2023 fro the analysis.
